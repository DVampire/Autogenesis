# Humanities and social science writing

Guidance specific to humanities and social science papers. Where the conventions are Chinese-specific — stock phrases, citation formats — the examples stay in Chinese with English glosses.

## 1. What makes humanities papers different

### Compared with STEM

| Aspect | STEM | Humanities / social science |
|--------|------|------------------------------|
| Core | Experimental data, technical methods | Argumentative logic, theoretical analysis |
| Structure | Standard IMRaD | Flexible |
| Figures | Mostly data charts | Mostly concept diagrams and flowcharts |
| Citations | Weighted to the last 5 years | Classic sources remain citable |
| Language | Concise and objective | May be somewhat literary |

### Common types

- **Literary criticism**: analysis of works, application of literary theory
- **Historical research**: source analysis, interpretation of events
- **Philosophy**: conceptual clarification, logical argument
- **Education research**: teaching practice, educational theory
- **Sociology**: analysis of social phenomena, survey research

## 2. Argument structures

### Common patterns

**Whole–parts–whole**
```
State the thesis -> sub-claim 1 + evidence -> sub-claim 2 + evidence -> sub-claim 3 + evidence -> synthesis
```

**Progressive**
```
Describe the phenomenon -> analyze causes -> deeper inquiry -> solution / theory building
```

**Contrastive**
```
Present position A -> present position B -> compare -> evaluate -> state your own position
```

**Problem-driven**
```
Pose the question -> review the literature -> theoretical framework -> analysis -> answer the question
```

### Elements of an argument

**Thesis**
- Clear, specific, arguable
- Not overly broad or absolute
- Weak: 鲁迅很伟大 ("Lu Xun was great")
- Strong: 鲁迅杂文中的讽刺手法体现了其批判现实主义精神 ("the satire in Lu Xun's essays embodies his critical realism")

**Evidence**
- Textual: quotations, close reading
- Theoretical: scholarly positions, theoretical frameworks
- Factual: historical events, statistics, cases

**Reasoning**
- The inference is explicit
- The evidence is tightly bound to the claim
- No logical leaps

## 3. Style

### Academic register

**Objectivity**
- Weak: 我认为这部作品非常感人 ("I find this work very moving")
- Strong: 该作品通过细腻的心理描写引发读者的情感共鸣 ("the work evokes an emotional response through its fine-grained psychological description")

**Precision**
- Weak: 很多学者都这样认为 ("many scholars think so")
- Strong: 王国维（1927）、朱光潜（1932）等学者均持此观点 ("Wang Guowei (1927) and Zhu Guangqian (1932) both hold this view")

**Formality**
- Use the discipline's technical vocabulary
- Avoid colloquialisms
- Keep person consistent (usually third person, or 本文 "this paper")

### Stock phrases

**Introducing a position**
- 就...而言 — as regards …
- 从...角度来看 — viewed from the perspective of …
- 在...语境下 — in the context of …
- 基于...理论 — drawing on the theory of …

**Analysis**
- 体现了... — embodies …
- 反映出... — reflects …
- 揭示了... — reveals …
- 呈现出... — presents …

**Evaluation**
- 具有...意义 — carries the significance of …
- 存在...局限 — is limited in that …
- 为...提供了新视角 — offers a new perspective on …
- 丰富了...的内涵 — enriches the meaning of …

### Expressions to avoid

| Avoid | Use instead |
|-------|-------------|
| 我觉得 (I feel) | 本文认为 / 笔者认为 (this paper argues) |
| 大家都知道 (everybody knows) | 学界普遍认为 (scholarly consensus holds) |
| 肯定是 (it must be) | 可以推断 / 有理由认为 (it may be inferred) |
| 绝对正确 (absolutely correct) | 具有一定的合理性 (has a degree of merit) |
| 完全错误 (completely wrong) | 存在值得商榷之处 (is open to question) |

## 4. Citing sources

### Types of citation

**Direct quotation**
- Short (under ~40 characters): run into the text, in quotation marks
- Long (over ~40 characters): set off as its own indented block, no quotation marks

**Paraphrase**
- Summarize another's position in your own words
- Still requires a citation

**Composite citation**
- Synthesize several scholars' positions
- Example: 关于这一问题，学界存在不同看法（张三，2020；李四，2021）

### Common Chinese humanities citation formats

**Book**
```
[1] 王国维. 人间词话[M]. 北京: 人民文学出版社, 1960: 15.
```

**Journal article**
```
[2] 钱钟书. 论"通感"[J]. 文学评论, 1962(1): 13-25.
```

**Classical text**
```
[3] [清]王夫之. 读通鉴论[M]. 北京: 中华书局, 1975: 卷十二.
```

**Translated work**
```
[4] [德]海德格尔. 存在与时间[M]. 陈嘉映, 王庆节, 译. 北京: 三联书店, 2006: 42.
```

## 5. Writing each section

### Introduction

**Elements**
1. Background and significance
2. State of the field (a condensed literature review)
3. Research question and objectives
4. Methods
5. Structure of the paper

**Guidance**
- Move from broad to narrow, focusing progressively
- Make the novel contribution or distinctive angle explicit
- Length: 10–15% of the paper

### Literature review

**Ways to organize**
- By theme
- Chronologically
- By school of thought
- By research method

**Guidance**
- Not a list — it must evaluate
- Name what prior work contributed and where it falls short
- Lead into why this study is needed

### Body

**Chapter structure**
- Chapter opening: the question this chapter answers
- Main discussion: developed section by section
- Chapter summary: the chapter's main positions

**Paragraph transitions**
- Use transition sentences between paragraphs
- Keep the argumentative logic continuous
- Return to the main thesis at appropriate points

### Conclusion

**Elements**
1. Summary of the main findings or positions
2. Theoretical contribution or practical significance
3. Limitations
4. Directions for future work

**Guidance**
- Introduce no new evidence
- Do not simply restate the body
- Elevate moderately, without overreaching

## 6. Quality checklist

### Argument
- [ ] Is the thesis clear and arguable?
- [ ] Is the evidence sufficient and reliable?
- [ ] Is the reasoning explicit?
- [ ] Are likely counterarguments addressed?

### Structure
- [ ] Does every chapter serve the theme?
- [ ] Are the chapters logically connected?
- [ ] Is anything repeated or missing?

### Citations
- [ ] Is the citation format consistent?
- [ ] Is each citation accompanied by analysis?
- [ ] Is there over-quotation?

### Language
- [ ] Does it meet academic register standards?
- [ ] Is the technical vocabulary used accurately?
- [ ] Are there colloquialisms?
